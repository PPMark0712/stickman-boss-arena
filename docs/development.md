# 开发与设计

目标引擎：Godot 4.7.2，GDScript，Compatibility 渲染器，1280 × 720。
所有游戏图形以矩形和基础几何图元实时绘制，声音运行时合成。主角朝右绘制，
朝左镜像。

## 模块

- `scripts/config.gd`：物理、攻击窗口、攻击几何、生命、能量等可调参数。
- `scripts/player.gd`：玩家显式状态机与复用的类型化输入帧。
- `scripts/behavior_tree.gd`：Condition / Action / Sequence / Selector 行为树。
- `scripts/boss.gd`：两种 Boss，共享行为树与不同招式时间轴。
- `scripts/arena.gd`：房间、命中判定、类型化特效、震屏和命中停顿。
- `scripts/main.gd`：选关、事件驱动 HUD、暂停、结果与本地最佳记录。

## 运行时约束

输入帧在玩家节点内复用，物理帧不创建控制字典。挥砍判定框、命中后坐与冲刺
统一读取 `ArenaConfig`。

生命、能量、Boss 血量与阶段通过信号刷新 HUD；常态帧只更新计时和提示透明度。
粒子、砸地和刀光使用类型化短生命周期对象，避免动态字典字段访问。

危险物清理会先关闭物理处理和显示，再排队释放，确保阶段切换当帧不会残留命中。
竞技场只恢复自己启动的全局时间缩放，并保留命中停顿前的缩放值。

## 当前手感

移动速度 350 px/s，水平方向直接响应输入，没有加速、减速或滑行惯性。
主角上升重力 2200 px/s²，下落重力 2850 px/s²；Boss 保持独立重力。
首跳速度 710 px/s，二段跳 635 px/s。
一段与二段跳共享脚底离地 126 px 的硬上限，即角色 70 px 身高的 1.8 倍。
土狼时间 110 ms，跳跃缓冲 140 ms；松开跳跃键可短跳。

攻击输入缓存 160 ms。普通 X 使用相同持续时间、伤害和横向判定，在两条
大幅度斜扫轨迹之间交替；挥砍期间再次按 X 可缓存下一次独立攻击。移动中
起手会保持并继续响应水平输入，静止起手则在本次挥砍内锁定移动。地面或空中
按 ↑ + X 可上劈，空中按 ↓ + X 可下劈；纵向判定宽于角色。三类攻击都使用
跨越身体两侧的剑轨迹与多层透视弧光。下劈命中后向上反弹并保留一次空中跳跃，
其他挥砍命中产生短距离后退。Boss 落石为圆形，上劈命中后不受重力影响，沿
竖直方向反弹并飞出屏幕。

C 向面朝方向冲刺 140 ms，速度 790 px/s，冷却 420 ms。冲刺不提供无敌，
接触敌人会正常受伤并立即进入受伤状态。受伤无敌时间为 900 ms。

角色转向和较重落地会产生矩形尘屑，落地姿态有短暂压缩。
主角使用带肘、膝关节的程序化骨骼动画和分段缓动；裂岩守卫使用实心矩形躯干，
左手握锤柄尾端、右手靠近右肩，短柄圆形刺锤停在脑后。锤头在砸落和空中旋转
期间使用跟随姿势与朝向的动态碰撞箱；Boss 身体和锤头在全部存活姿势中均有
接触伤害。锤柄和锤头为黑色金属，尖刺和铆钉为金色。武器按朝向切换前后遮挡层级。
裂岩守卫的后手先于躯干绘制，前手后于躯干绘制，镜像时同步交换虚实关系。
挥剑有效帧同步生成刀光，命中叠加白闪、粒子和短暂停顿。

## 能量与 A 键

每次有效剑击 +1 能量，上限 9；法术和完整治疗各消耗 3。
A 在 100 ms 内松开发波，100–300 ms 松开不触发效果。按住 300 ms 后进入
治疗，再蓄力 1 秒，并在蓄力的 1/3、2/3、3/3 处各扣 1 点能量；每轮总计
1.3 秒恢复 1 点生命。头顶进度条只显示 1 秒蓄力阶段。松开或受伤会立即中断，
已经扣除的能量不返还；中断后须松开重按。完成后若 A 仍按住、生命未满且至少
还有 3 点能量，则自动进入下一轮 300 ms 准备和 1 秒蓄力。能量不足、生命已满、
空中无法治疗均显示提示，治疗释放不会意外发波。

## Boss

**裂岩守卫 / The Quarry**：慢速压迫、锤击、向前传播的不规则碎岩波、
跳砸；地震波高 78 px，略高于主角。首次落点不显示地面范围，改由明显举锤动作
传达前摇。半血后加速跳砸并生成双向波；双锤连段从每次冲击姿势直接回举，随后
起跳并仅在上升段旋锤，顶点举锤警示并短暂停顿，再快速直落。最终落地生成居中的
大范围红色冲击、强震屏与双向地震波。左右连续砸地会引发有落点预警的圆形落石。

**折光剑使 / The Prism**：快速突刺、回旋刃、空中俯冲；半血后
增加折返突刺、三刃扇射与有预警的多次折光落剑。
各招都有前摇和后摇，避免不可读的瞬间命中。

## 迭代验证

每个功能阶段运行 Godot headless 检查与相关玩法测试后 commit。当前测试包含
55 项玩家状态检查和 180 项真实场景/物理集成检查，其中包含裂岩守卫所有关键
姿势的双臂等长约束、锤头镜像碰撞，以及玩家两段对角挥砍的右肘 IK 分支。
完整版本还需实际导出 Web、浏览器验证启动/选关/战斗/暂停/重试。
自动测试验证机制，人工试玩用于继续调整难度与手感。
