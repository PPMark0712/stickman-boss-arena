# 开发与设计

目标引擎：Godot 4.7.2，GDScript，Compatibility 渲染器，1280 × 720。
所有游戏图形由矩形绘制，声音运行时合成。主角朝右绘制，朝左镜像。

## 模块

- `scripts/config.gd`：物理、攻击窗口、攻击几何、生命、能量等可调参数。
- `scripts/player.gd`：玩家显式状态机与复用的类型化输入帧。
- `scripts/behavior_tree.gd`：Condition / Action / Sequence / Selector 行为树。
- `scripts/boss.gd`：两种 Boss，共享行为树与不同招式时间轴。
- `scripts/arena.gd`：房间、命中判定、类型化特效、震屏和命中停顿。
- `scripts/main.gd`：选关、事件驱动 HUD、暂停、结果与本地最佳记录。

## 运行时约束

输入帧在玩家节点内复用，物理帧不创建控制字典。连击位移、判定框和受击后坐
统一读取 `ArenaConfig`，避免攻击有效帧内重复创建数组。

生命、能量、Boss 血量与阶段通过信号刷新 HUD；常态帧只更新计时和提示透明度。
粒子、砸地和刀光使用类型化短生命周期对象，避免动态字典字段访问。

危险物清理会先关闭物理处理和显示，再排队释放，确保阶段切换当帧不会残留命中。
竞技场只恢复自己启动的全局时间缩放，并保留命中停顿前的缩放值。

## 当前手感

移动速度 350 px/s，地面加速度 3500 px/s²，减速 4300 px/s²。
上升重力 1900 px/s²，下落 2450 px/s²。
首跳速度 710 px/s，二段跳 635 px/s。
土狼时间 110 ms，跳跃缓冲 140 ms；松开跳跃键可短跳。

攻击输入缓存 160 ms，地面三连击分别持续 250 / 270 / 340 ms，并为每段配置
独立前摇、有效帧、位移和剑刃轨迹。挥砍期间再次按 X 会缓存下一段，
收招后 300 ms 内再次攻击也可继续连段。第三段距离更远且命中反馈更强。
空中攻击持续 290 ms，方向劈斩开始时会短暂稳定纵向速度；
下劈命中弹起并恢复一次空中跳跃。受伤无敌 900 ms。

角色转向和较重落地会产生矩形尘屑，落地姿态有短暂压缩。
挥剑有效帧同步生成刀光，命中时叠加白闪、粒子、震屏和短暂停顿。

## 能量与 A 键

每次有效剑击 +1 能量，上限 9；法术和治疗各消耗 3。
短按 A（少于 220 ms）后松开发波；按住进入治疗，在 1.5 秒时恢复 1 点生命。
一次按住只治疗一次。治疗期间移动、跳跃、攻击或受伤均中断；
中断后须松开重按。治疗释放不会意外发波。
能量不足、生命已满、空中无法治疗均显示提示。

## Boss

**裂岩守卫 / The Quarry**：慢速压迫、锤击、向前传播的不规则碎岩波、
跳砸；半血后加速跳砸并生成双向波，双锤 → 腾空旋锤 → 追踪落砸，
左右连续砸地引发有落点预警的落石。

**折光剑使 / The Prism**：快速突刺、回旋刃、空中俯冲；半血后
增加折返突刺、三刃扇射与有预警的多次折光落剑。
各招都有前摇和后摇，避免不可读的瞬间命中。

## 迭代验证

每个功能阶段运行 Godot headless 检查与相关玩法测试后 commit。当前测试包含
25 项玩家状态检查和 73 项真实场景/物理集成检查。
完整版本还需实际导出 Web、浏览器验证启动/选关/战斗/暂停/重试。
自动测试验证机制，人工试玩用于继续调整难度与手感。
