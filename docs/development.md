# 开发与设计

目标引擎：Godot 4.7.2，GDScript，Compatibility 渲染器，1280 × 720。
所有游戏图形以矩形和基础几何图元实时绘制，声音运行时合成。主角朝右绘制，
朝左镜像。

## 模块

- `scripts/config.gd`：物理、攻击窗口、攻击几何、生命、能量等可调参数。
- `scripts/player.gd`：玩家显式状态机与复用的类型化输入帧。
- `scripts/behavior_tree.gd`：Condition / Action / Sequence / Selector 行为树。
- `scripts/boss.gd`：两种 Boss，共享行为树与不同招式时间轴。
- `scripts/arena.gd`：房间、命中判定、类型化特效、震屏和命中停顿。
- `scripts/main.gd`：选关、事件驱动 HUD、暂停、结果与本地最佳记录。

## 运行时约束

输入帧在玩家节点内复用，物理帧不创建控制字典。挥砍判定框、命中后坐与冲刺
统一读取 `ArenaConfig`。

生命、能量、Boss 血量与阶段通过信号刷新 HUD；常态帧只更新计时和提示透明度。
粒子、砸地和刀光使用类型化短生命周期对象，避免动态字典字段访问。

危险物清理会先关闭物理处理和显示，再排队释放，确保阶段切换当帧不会残留命中。
竞技场只恢复自己启动的全局时间缩放，并保留命中停顿前的缩放值。
致死命中的后续特效不会重新开启时间缩放。法术使用前后位置的判定框合并来覆盖
水平飞行路径，避免高速穿透与贴身发射漏判；此算法适用于当前的水平直线法术。

## 当前手感

移动速度 350 px/s，水平方向直接响应输入，没有加速、减速或滑行惯性。
主角上升重力 2200 px/s²，下落重力 2850 px/s²；Boss 保持独立重力。
一段和二段跳速度均为 736 px/s；长按时，每一段都会从各自起跳点上升约
126 px，即角色 70 px 身高的 1.8 倍。
土狼时间 110 ms，跳跃缓冲 140 ms；松开跳跃键可短跳。

攻击输入缓存 160 ms。普通 X 使用相同持续时间、伤害和横向判定，在两条
大幅度斜扫轨迹之间交替；挥砍期间再次按 X 可缓存下一次独立攻击。移动中
起手会保持并继续响应水平输入，静止起手则锁定移动到有效判定结束。挥砍中
可以后退，但当前刀的朝向固定，下一刀记住按键当时的上下方向和水平朝向。地面或空中
按 ↑ + X 可上劈，空中按 ↓ + X 可下劈；纵向判定宽于角色。三类攻击都使用
跨越身体两侧的剑轨迹与多层透视弧光。下劈命中后向上反弹并保留一次空中跳跃，
其他挥砍命中产生短距离后退。Boss 落石为圆形，上劈命中后不受重力影响，沿
竖直方向反弹并飞出屏幕。

C 向面朝方向冲刺 140 ms，速度 790 px/s，冷却 420 ms。冲刺不提供无敌，
接触敌人会正常受伤并立即进入受伤状态。受伤无敌时间为 900 ms。
冲刺输入缓存 120 ms；冲刺结束同帧可衔接缓存攻击或跳跃。C 可主动取消治疗，
保留已消耗能量并锁住本次 A 键长按。施法前 160 ms 不可被跳跃、冲刺或剑击取消，
后 80 ms 可以用跳跃、冲刺或缓存剑击取消；施法时可移动和后退，发射方向保持
固定。无方向键的攻击/冲刺缓存也记住按下时的朝向。受伤清空旧攻击、跳跃和
冲刺请求，受伤结束当帧响应新输入。缓存跳跃期间提前松键仍会产生短跳，
起跳当帧即进入空中状态；下劈反弹清除旧的松键请求，避免反弹高度被意外截断。

角色转向和较重落地会产生矩形尘屑，落地姿态有短暂压缩。
主角使用带肘、膝关节的程序化骨骼动画和分段缓动；裂岩守卫使用实心矩形躯干，
左手握锤柄尾端、右手靠近右肩，短柄圆形刺锤沿肩部斜向后扛，锤头中心与头部
中心齐平。锤头在砸落和空中旋转
期间使用跟随姿势与朝向的动态碰撞箱；Boss 身体和锤头在全部存活姿势中均有
接触伤害。锤柄和锤头为银色金属，尖刺和铆钉为金色。武器按朝向切换前后遮挡层级。
裂岩守卫的后手先于躯干绘制，前手后于躯干绘制，镜像时同步交换虚实关系。
挥剑有效帧同步生成刀光，命中叠加白闪、粒子和短暂停顿。

## 能量与 A 键

每次有效剑击 +1 能量，上限 9；法术和完整治疗各消耗 3。
A 在 100 ms 内松开发波，100–300 ms 松开不触发效果。按住 300 ms 后进入
治疗，再蓄力 1 秒，并在蓄力的 1/3、2/3、3/3 处各扣 1 点能量；每轮总计
1.3 秒恢复 1 点生命。头顶进度条只显示 1 秒蓄力阶段。松开或受伤会立即中断，
已经扣除的能量不返还；中断后须松开重按。完成后若 A 仍按住、生命未满且至少
还有 3 点能量，则自动进入下一轮 300 ms 准备和 1 秒蓄力。能量不足、生命已满、
空中无法治疗均显示提示，治疗释放不会意外发波。

## Boss

**裂岩守卫 / The Quarry**：慢速压迫、锤击、向前传播的不规则碎岩波、
跳砸；地震波为 86 × 78 px，宽度略大于高度且高度略高于主角。首次落点不显示
地面范围，改由明显举锤动作传达前摇。两阶段跳砸的起跳速度分别为 870 px/s 和
960 px/s；上升时保持举锤，下降时按最高点至地面的实际距离推进砸锤动画，触地
帧刚好进入冲击姿势并结算伤害。半血后加速跳砸并生成双向波；双锤连段从每次
冲击姿势直接回举，随后以 930 px/s 起跳并仅在上升段旋锤；离地时锁定玩家位置，
顶点不再追踪，举锤警示并停顿 300 ms 后向锁定点快速直落。最终落地生成居中的
大范围红色冲击、强震屏与双向地震波。
连招下降同样按离地距离推进落锤，普通跳砸与连招终结均在物理检测到触地的
当帧结算。半血先标记免伤，完成当前招式及收锤后再进入转阶段，避免腾空动作
被打断。二阶段地面锤击保证完整的 320 ms 收锤时间。
左右连续砸地会引发有落点预警的圆形落石。

**折光剑使 / The Prism**：快速突刺、回旋刃、空中俯冲；半血后
增加折返突刺、三刃扇射与有预警的多次折光落剑。
各招都有前摇和后摇，避免不可读的瞬间命中。

## 迭代验证

每个功能阶段运行 Godot headless 检查与相关玩法测试后 commit。当前测试包含
75 项玩家状态检查和 216 项真实场景/物理集成检查，其中包含裂岩守卫所有关键
姿势的双臂等长约束、锤头镜像碰撞，以及玩家两段对角挥砍的右肘 IK 分支。
还覆盖输入收招衔接、同姿势重复出刀、双向高速/贴身法术、免伤及墙面消散、
致死时间缩放，以及腾空期间触发半血后的完整落地与转阶段。
完整版本还需实际导出 Web、浏览器验证启动/选关/战斗/暂停/重试。
自动测试验证机制，人工试玩用于继续调整难度与手感。

## 在编辑器中调整程序化动画

角色仍由 `BoxArt` 的矩形和线段实时绘制，不需要图片或精灵表。打开
`scenes/fighter_visual.tscn`，选中根节点后可在 Inspector 的 `Fighter Kind`
切换主角、裂岩守卫和折光剑使的预览；再选中 `AnimationPlayer`，即可在底部
动画面板选择和播放时间轴。

`attack_a` / `attack_b` 是主角两次交替横斩，`up` / `down` 是上下劈；
`windup` / `slam` / `recover` / `apex` / `dive` / `impact` / `settle` 供裂岩守卫使用。
`attack` 是裂岩守卫的空中旋锤。折光剑使保留原程序动画采样。
移动 `animation_progress` 轨道上的关键帧可调整蓄力、挥出和收招的节奏，修改
关键帧的 Transition 可改变缓动。游戏运行时会采样同一条时间轴，因此保存场景
后即可在实战中看到变化。战斗判定的总时长仍由 `ArenaConfig` 和 Boss 招式脚本
决定；时间轴负责在这段时长内如何推进姿势。裂岩守卫的锤头判定使用采样后的
姿势，始终跟随锤头画面。

当前时间轴控制“姿势推进”，具体关节坐标和武器轨迹仍定义在
`scripts/box_art.gd`。若需要在 2D 视口中直接拖动每一只手、脚和武器，应继续将
肢体拆为独立 Node2D 或 Bone2D；这会是另一层编辑器化改造，不需要改成图片。

`tools/create_animation_timeline.gd` 用于从默认规格重建时间轴场景。它会覆盖
`scenes/fighter_visual.tscn`，完成手工调帧后不要再次运行，除非明确要恢复默认
时间轴。

## 战斗动作与反馈优化

主角状态切换时在关节位置之间做 35–75 ms 的短过渡，攻击/受伤/冲刺优先快速
到位；连续同类攻击也会从上一刀的当前姿势开始过渡。跑步和呼吸使用连续时钟，
避免动画长度和正弦周期不同导致循环接缝。移动横斩、上劈和施法保留腿部步伐，
原地出手保持支撑姿态；可通过 Inspector 的 `Horizontal Velocity` 预览步伐。
待机双脚贴地，下落时逐渐伸腿准备落地。横斩包含 55 ms 准备、快速挥出和
较慢收招，拖影集中在挥出阶段。攻击总时长和伤害窗口仍由 `ArenaConfig` 控制。

裂岩守卫的地面招式在原定冲击时刻前 160 ms 开始落锤，到达 impact 姿势才
结算砸地；第二锤在抬锤阶段锁定朝向。落锤后经过短暂停留，再先向上提锤、
绕回肩后，避免武器穿过地面。锤头外缘在 impact 姿势与地面齐平，碰撞位置
包含实际绘制使用的呼吸偏移和受击位移。抬锤、落锤、连招顶点有独立合成音效。
绘制和锤头判定共用 `BoxArt.heavy_rig_snapshot()` 的关节及武器坐标。

普通命中使用实际重叠区域生成短促放射闪光与定向火星；普通剑击停顿 42 ms，
震屏采用指数衰减振动。冲刺留下最多 8 个短寿命姿势残影，锤头高速运动产生
轨迹；砸地改为贴地亮线、碎石尖峰和扩散冲击。刀光按游戏时间衰减，命中停顿
时不会提前消失。治疗增加手边聚能圆弧与光点。
下劈命中使用更强火星、55 ms 停顿和重击音效，上劈反弹落石使用向上的接触火花。
施法增加空手推掌、后坐和收回，持剑手保持低位。弹体有白色核心、青色外层与
渐隐尾迹，亮部与 62 × 38 px 判定框对齐；尾迹不造成伤害。法术命中生成双层
扩散环、定向碎片、60 ms 停顿与独立冲击音，撞墙或遇到免伤时播放较小的消散
效果。法术伤害仍为 24，消耗仍为 3 能量。

可运行 `godot --path . --script res://tools/preview_combat.gd` 生成可复现画面检查，
需要图形显示环境，输出在 `test-results/feel-*.png`。预览用于核对关键姿势和
效果，主观手感仍需在 F5 运行后的练习模式里实战检验。
其中 `feel-spell-flight.png` / `feel-spell-impact.png` 展示法术发射与命中，
`feel-cast-dive-sheet.png` 展示施法收招与裂岩守卫下降落锤的关键姿势。
